# Lesson AI
Стек запущен 02.10.2026 на VPS 169.58.83.125. Основной адрес https://projector-school.info, Caddy -> 127.0.0.1:8091 на самом VPS.
FastAPI, PostgreSQL 16, Redis 7 с AOF, очередь RQ lessons, worker с ffmpeg. Общий materials volume. Backend только 127.0.0.1:8091, базы без публичных портов.
Скопировать .env.example в .env, задать случайный POSTGRES_PASSWORD, chmod 600 .env. API ключи только в .env.
Проверка: docker compose --env-file .env config --quiet
Запуск: docker compose up -d --build
Проверка: curl --fail http://127.0.0.1:8091/healthz
Это инфраструктурный каркас. Загрузка, STT/LLM адаптеры, схема БД и задачи анализа ещё не реализованы. Перед production фиксировать зависимости lock-файлом и образы digest.
Перед публикацией: DNS A/AAAA, авторизация и ограничения загрузок. Сохранить Caddyfile, добавить только новый блок, Caddy validate, затем reload. Проверить reports /healthz до/после. Публикация — отдельный шаг.
Бэкапы: pg_dump, архив materials, защищённая .env, проверка восстановления. Не использовать down -v.

## Аудио и обрезка
В кабинете: MP3 до 250 МБ, лимит аккаунта 2 ГБ (исходник + сохранённый фрагмент). Плеер поддерживает перемотку. Обрезка задаётся временем мин:сек или по текущей позиции исходного плеера. Исходник не меняется; восстановление снимает обрезку. Скачивание и основной плеер используют сохранённый фрагмент. При подключении STT выбирать .trim.mp3 при trim_size > 0, иначе .mp3; начало транскрипта соответствует trim_start исходной записи. Обрезка через MP3 stream copy, границы с точностью аудиокадра. Проверки: stage3-test.py.

Редактор волны: WaveSurfer.js 7.8.14 (BSD, локально размещён), Regions + Timeline. Спектр амплитуд создаётся на сервере и кэшируется рядом с исходником; браузер не декодирует целый урок. Две границы, масштаб, прослушивание выделения.

Изменение политики хранения по указанию пользователя: после сохранения фрагмент заменяет запись; исходник удаляется после успешной транзакции. Временная копия служит только для отката при ошибке. Плеер, скачивание и будущий STT используют единственный .mp3; длительность и размер обновляются, кэш волны сбрасывается. Возврата исходника нет. Перед сохранением — подтверждение удаления краёв.

Оформление основано на логотипе школы с https://www.projector-school.ge/ : тёмно-синий, бирюзовый, салатовый, белый. Используемые HEX подобраны по публичному логотипу, официальный брендбук не предоставлен. Логотип локально /assets/editor/school-logo.png, источник Wix 58a27e_8dcf1ec5f6144428bc7b7543dff22d00.
